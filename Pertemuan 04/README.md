# Pertemuan 04 - CSS3 Layout dan Responsive Web Design

## Pengembangan

Perubahan yang dilakukan: Menata halaman profil menggunakan CSS Grid, Flexbox, dan media query. Navigasi ditampilkan dengan Flexbox; konten utama memakai satu kolom pada viewport di bawah 768px dan dua kolom mulai dari 768px. Gambar dan input formulir dibuat menyesuaikan lebar area.
Commit dan push GitHub: Status commit dan push tidak dapat dipastikan dari file `index.html` dan `style.css`.

## Pengujian

- Perangkat bergerak: Belum ada hasil pengujian aktual. Berdasarkan CSS, viewport di bawah 768px menggunakan satu kolom.
- Desktop: Belum ada hasil pengujian aktual. Berdasarkan CSS, viewport mulai 768px menggunakan dua kolom.
- Galat dan perbaikan: Pada `index.html`, tanda kutip atribut `placeholder` pada textarea tampak belum ditutup sebelum `required`, sehingga `required` dapat terbaca sebagai bagian dari nilai placeholder. Perbaikan belum tercatat.
- Validasi CSS: Belum ada hasil validasi CSS yang dapat dipastikan dari file yang tersedia.
