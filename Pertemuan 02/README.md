# Pertemuan 2 - HTML5 Dasar dan Struktur Semantik
## Tujuan
Membangun halaman profil sederhana menggunakan struktur
HTML5 yang valid dan elemen semantik.
## Bukti Praktik
- Struktur dokumen HTML5 valid
- Elemen semantik digunakan sesuai fungsi
- Teks, daftar, tautan, dan gambar digunakan dengan
atribut sesuai
- Dokumen HTML sudah divalidasi dan galat diperbaiki
## Riwayat
Commit dan push dilakukan secara bertahap selama proses
pengembangan.
## Artefak
- `taklengkap.html` - latihan error tolerance browser.
- `emmet.html` - latihan Emmet dan struktur HTML5.
- `index.html` - artefak utama halaman profil P2.
- `img/foto - profil.jpg` - gambar yang digunakan pada halaman profil.
## Implementasi
Pada P2 saya membangun halaman profil menggunakan struktur HTML5 yang valid,
elemen semantik, teks, daftar, tautan, dan gambar.
## Validasi HTML
- Berkas yang divalidasi: `index.html`
- Galat yang ditemukan: [bagian foto profile nya , kadang bisa kadang tidak ]
- Perbaikan yang dilakukan: [mengubah format file foto,dan nama file fotonyanya yang berada di img src]
- Hasil validasi akhir: [tampilan sudah seperti yang diperlukan]
